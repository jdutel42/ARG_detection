# Plasmid and ARG Analysis in Soil Metagenomes (GitHub Mirror)

⚠️ **This GitHub repository is a mirror and redirection point. The full project, data, and pipelines are hosted on GitLab due to size and hosting requirements.**

---

## Project Overview

This project applies cutting-edge bioinformatics tools to analyze plasmids and antibiotic resistance genes (ARGs) in soil metagenomes, aiming to understand ARG dynamics within plasmid populations and their environmental responses.

### Tools Used

* **PlasFlow:** Neural network-based plasmid prediction tool with up to 96% accuracy. [GitHub](https://github.com/smaegol/PlasFlow)
* **ARGS-OAP:** Tool for ARG identification and quantification from PlasFlow outputs. [GitHub](https://github.com/xinehc/args_oap)

### Data Highlights

* 69 soil metagenomes sampled over 7 years from ecosystems affected by underground fires.
* Focus on microbial community influence and temperature effects on ARG distribution.
